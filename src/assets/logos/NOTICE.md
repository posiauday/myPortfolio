# Microsoft Power Platform icons — usage notice

The SVGs in this folder are Microsoft's own official product icons, from the
"Power Platform icons (scalable)" package published for the Power Platform
Architecture Center. They are used here unmodified (original colors, no
crop/flip/rotate/distortion) to illustrate which Microsoft products this
portfolio's work is built on — the permitted "architectural diagrams,
training materials, or documentation" use under Microsoft's terms, not to
represent this site's own product or service.

Per Microsoft's stated terms:

- Icons may be resized but not cropped, flipped, rotated, or have their
  shape distorted.
- The full product name must appear near each icon (not overlapping it) —
  see the labeled legend under the orbit diagram in `PlatformOrbit.jsx`,
  which pairs every icon with its name.
- These icons may only represent the Microsoft product each was designed
  for, never this site's own product or service.
